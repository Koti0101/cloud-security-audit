# Cloud Security Audit Checklist
> By Koti Favour | Aspiring Cloud Security Engineer | Available Jan 2027

This project is a simple security checklist for AWS & Azure for beginners learning cloud security.

## What I Checked
- [x] S3 Buckets should NOT be public
- [x] Security Groups should NOT allow 0.0.0.0/0 on port 22
- [x] MFA should be enabled for root account
- [x] Azure Storage should have Secure Transfer enabled
- [x] Public IP should NOT be open
